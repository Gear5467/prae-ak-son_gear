# Card Stunt Controller · MVP

แอปช่วยแปรอักษรตามสเปก ระยะ 1 (MVP) มือถือนักเรียนบอกว่าต้องชูแผ่นสีอะไร และนับ 1 2 3 ให้ตรงกันทุกเครื่อง

## วิธีรัน

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
```

```bash
DIRECTOR_PASSWORD=ตั้งรหัสเอง npm start
```

- หน้าผู้ควบคุม: `http://localhost:3000/director`
- หน้าต่างเซิร์ฟเวอร์จะแสดงที่อยู่ในวง LAN (เช่น `http://192.168.1.231:3000`) ให้มือถือที่อยู่ใน Wi-Fi เดียวกันใช้
- ถ้าไม่ตั้ง `DIRECTOR_PASSWORD` ระบบจะสุ่มรหัสให้ แล้วพิมพ์ไว้ในหน้าต่างเซิร์ฟเวอร์

## ขั้นตอนใช้งาน

1. **ตั้งค่าสแตนด์**: กำหนดโซนและจำนวนที่นั่งต่อแถว เขียนได้ 2 แบบ คือ `24x20` (24 ที่นั่ง × 20 แถว) หรือ `20,20,22,22` (เรียงจากแถว 1) คลิกบนผังเพื่อทำเครื่องหมายช่องที่ไม่ใช้ แล้วตั้งชุดสีแผ่นพร้อมเลขหน้า
2. **คลังภาพ**: มีภาพสำเร็จรูป 8 ภาพ ระบบย่อ/ขยายให้พอดีกับผังเอง
3. **วาดภาพ**: มีดินสอ ถังสี เส้น สี่เหลี่ยม วงกลม ดูดสี ย้อน/ทำซ้ำ กลับซ้ายขวา วางข้อความไทย และนำเข้ารูป PNG/JPG/SVG
4. **ชุดการแสดง**: ลากสลับลำดับภาพได้ และแต่ละภาพบอกว่าต้องเปลี่ยนสีกี่ที่นั่ง เมื่อกด **เผยแพร่** ระบบจะสร้างบทรายที่นั่ง ในแท็บนี้ยังมีลิงก์และ QR สำหรับนักเรียนด้วย
5. **ควบคุมสด**: มีปุ่มเตรียมภาพถัดไป · เริ่มนับ 1 2 3 · ลดแผ่น · ข้ามภาพ · ย้อนภาพ · หยุดฉุกเฉิน (สองปุ่มหลังต้องกดค้าง) หน้านี้แสดงจำนวนเครื่องออนไลน์ แผนที่ที่นั่ง และค่าคลาดของการนับรอบล่าสุดที่เครื่องนักเรียนรายงานกลับมา
6. **ตรวจภาพ**: แตะหรือลากเลือกช่องที่ผิด แล้วกดส่งแจ้งเตือน เครื่องนักเรียนจะกระพริบแดงและสั่น เมื่อนักเรียนกด “แก้แล้ว” ผู้ตรวจจะกด “ยืนยันถูก” หรือ “แจ้งซ้ำ” ก็ได้

นักเรียนสแกน QR แล้วเลือกโซน → แถว → เลขที่ จากนั้นยืนยันกับผังย่อที่บอกที่นั่งข้างๆ ถ้าเติม `&seat=B-12-07` ต่อท้ายลิงก์ จะได้ QR สำหรับติดเก้าอี้ที่ข้ามขั้นเลือกที่นั่งไปเลย

## ทดสอบความพร้อมกันของการนับ

ตอนเซิร์ฟเวอร์รันอยู่และเผยแพร่ชุดการแสดงแล้ว:

```bash
DIRECTOR_PASSWORD=รหัส node tools/loadtest.js --n 1920 --jitter 200
```

สคริปต์จะจำลองมือถือ N เครื่อง ซิงค์นาฬิกาแบบเดียวกับหน้า Seat สั่งนับ 3 รอบ แล้ววัดค่าคลาดของเลข "1"
`--jitter` ใส่ความหน่วงสุ่มทั้งขาไปและขากลับ เพื่อจำลองเน็ตในสนามที่แกว่ง

ผลบน MacBook เครื่องเดียว (22 พ.ย. 2569):

| การทดสอบ | คลาด p95 | คลาดสูงสุด | ได้คำสั่งก่อนเวลาเริ่ม |
|---|---|---|---|
| 1,920 เครื่อง ไม่มี jitter | 0.9 ms | 1.3 ms | ครบทุกเครื่อง |
| 1,000 เครื่อง jitter 0–200 ms | 26.9 ms | 42.3 ms | ครบทุกเครื่อง |

ผลนี้พิสูจน์แค่ตัววิธีซิงค์ เกณฑ์ผ่าน MVP ตามสเปก (ซ้อมจริง 1 โซนแล้ววัดได้ว่าคลาดไม่เกิน 50 ms) ยังต้องทดสอบกับมือถือจริงในสนาม

## การทำงานของการซิงค์

- เครื่องนักเรียนส่ง ping 10 ครั้ง ใช้รอบที่ RTT ต่ำสุด คำนวณ `offset = serverTime + RTT/2 − localTime` และวัดซ้ำทุก 30 วินาที
- เมื่อกดนับ เซิร์ฟเวอร์ส่ง `{ imageIndex, startAt, beatMs }` โดย `startAt` = เวลาตอนนี้ + 1.5 วินาที
- แต่ละเครื่องคำนวณจังหวะเองใน `requestAnimationFrame` ถ้าคำสั่งมาช้าก็กระโดดไปจังหวะปัจจุบันทันที และจะไม่สั่นย้อนหลัง

## สิ่งที่ต่างจากสเปก / ข้อจำกัดของ MVP

- **ฐานข้อมูล**: เก็บใน `data/db.json` ส่วนสถานะสดและจุดผิดเก็บในหน่วยความจำ ซึ่งรองรับเซิร์ฟเวอร์เดียว ถ้าต้องการ PostgreSQL/Redis ตามสเปกต้องทำเพิ่มในระยะ 2 ไฟล์นี้มีรหัสผ่าน Director อยู่ด้วย ห้ามแชร์
- **ไม่ใช้เฟรมเวิร์ก**: หน้าเว็บเขียน JavaScript ล้วน ไม่ต้อง build หน้า Seat มีขนาดราว 30 KB (สเปกกำหนดไม่เกิน 300 KB)
- **HTTPS**: Wake Lock (กันจอดับ) และ Service Worker (เปิดหน้าได้ตอนออฟไลน์) ทำงานเฉพาะบน HTTPS หรือ localhost ถ้าใช้ผ่าน `http://192.168.x.x` จอยังดับเองได้ ก่อนใช้งานจริงต้องวางเซิร์ฟเวอร์หลัง HTTPS เช่น Caddy หรือ Cloudflare Tunnel
- **iPhone**: Safari ไม่รองรับการสั่น (`navigator.vibrate`) iPhone จึงเห็นได้แค่จอ
- **ผู้ควบคุมสำรอง**: เปิดหน้า Director ได้หลายเครื่อง และทุกเครื่องสั่งได้ ยังไม่มีระบบส่งสิทธิ์ต่อ
- **ที่นั่งซ้ำ**: ระบบเตือนนักเรียน และให้ยืนยันเพื่อแทนที่เครื่องเดิมเอง ส่วนการส่งให้หัวหน้าโซนยืนยันรอหน้าหัวหน้าโซนในระยะ 2
- **ยังไม่ทำ (ระยะ 2–3)**: ภาพเคลื่อนไหว/คลื่น · หน้าหัวหน้าโซน · ตรวจนั่งเลื่อน · สรุปหลังซ้อม · แจ้งทั้งเซ็ต · จัดการที่นั่งว่าง · ตรวจภาพด้วยกล้อง · จอมือถือเป็นจุดสี · เซิร์ฟเวอร์ LAN · เสียงผ่านลำโพง
- **จำนวนเครื่อง**: ทดสอบไปแล้ว 1,920 เครื่องบนเครื่องเดียว เป้า 5,000 เครื่องต้องทดสอบบนเซิร์ฟเวอร์จริง

## โครงสร้างไฟล์

```
server.js            HTTP + WebSocket, เผยแพร่บท, ซิงค์, แจ้งจุดผิด
public/shared.js     ผังสแตนด์ → กริด, ชุดสี, คำนวณบท (ใช้ทั้งเซิร์ฟเวอร์และเบราว์เซอร์)
public/seat.html     หน้านักเรียน (PWA)
public/director.*    หน้าผู้ควบคุม / ผู้ออกแบบ / ผู้ตรวจ
tools/loadtest.js    ทดสอบโหลดและความแม่นของการซิงค์
```
